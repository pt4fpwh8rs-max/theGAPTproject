_ Por qué
documentar
primero

Un proyecto de arquitectura no termina cuando el cliente recibe las llaves. Termina cuando cada decisión —de sitio, de programa, de material— está registrada con honestidad.

No subimos fotos rápidas. Documentamos el proceso completo: desde el primer croquis hasta el detalle que nadie nota pero que hace que el espacio funcione.

Mientras preparamos eso, puedes escribirnos. Cada proyecto nace de una conversación.
