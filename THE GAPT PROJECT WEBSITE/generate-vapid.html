_ Generador de claves VAPID

Estas claves son necesarias para las notificaciones push. Genéralas una sola vez y guárdalas como secretos en Cloudflare.

VAPID_PUBLIC_KEY (para Cloudflare Workers + GAPT One)
VAPID_PRIVATE_KEY (solo para Cloudflare Workers — no compartir)

⚠ Guarda estas claves ahora. La clave privada no se puede recuperar una vez que cierres esta página.

Paso 1 — Cloudflare Workers:
Ve a tu Worker en gapt-mail → Settings → Variables → Add variable
Agrega: VAPID_PUBLIC_KEY y VAPID_PRIVATE_KEY como secretos.
Paso 2 — GAPT One (deploy/one/index.html):
Reemplaza REPLACE_WITH_YOUR_VAPID_PUBLIC_KEY con la clave pública de arriba.
La constante está en la línea: const VAPID_PUBLIC_KEY = '...';
Paso 3 — Deploy:
Haz deploy del worker actualizado y sube el index.html de GAPT One.
Luego abre GAPT One en tu iPhone, inicia sesión y acepta las notificaciones.
